The folder is the researcher.

Achiote operates as a model-agnostic folder researcher for food-memory reconstruction. It plans, researches, reasons, and returns a Memory Receipt with local sourcing, language clues, and evidence boundaries intact.

Inside the folder

The research engine runs locally in a model workspace. You own the process; the folder supplies bounded instructions, source discipline, and a repeatable proof trail.

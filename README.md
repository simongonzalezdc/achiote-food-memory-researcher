# Achiote (food memory researcher)

Folder-based AI food-memory researcher. Drop it into a Claude project; it investigates a half-remembered family dish from a sound-alike, a smell, or a color, then hands you one small taste to test the memory.

**Who it is for:** people chasing diaspora / family food memories with an honest research loop (not recipe spam).

**What you get:** a Claude-project research assistant pack for food-memory investigation.

## Try it

```bash
git clone https://github.com/simongonzalezdc/achiote-food-memory-researcher.git
cd achiote-food-memory-researcher
# load the project instructions into Claude (or your agent) per files in-tree
```
